Vision

A native, lightweight Linux DAW for making beats fast.

DawLunix is a normal Linux application. The drum grid, the playlist, the piano roll, and the mixer live in the same window, so a beat can start without a pile of setup. It is aimed at people who want to work quickly and hear the idea back as audio.

Features

What is in the window

Playlist and piano roll

The playlist is the arrangement. Tracks can be renamed, another lane can be added, and the lane list scrolls when it grows. The timeline scrolls sideways out to bar 300.

MIDI clips and imported WAV or MP3 audio sit on the same lanes. Open the piano roll and the notes belong to that clip: move a note and the playlist stays in step with it. C cuts the selected clip at the playhead. S toggles stretch on the selected clip.

dSynth and its sampler

dSynth is the built-in sampler, one on each playlist track. It opens from the dS button. A factory bank of eight sounds is already there: 808morphC, alienmorphC, bassmorphC, coolshiC, morphC, pluckC, poizC, and stringC.

The Sampler row imports your own WAV, AIFF, FLAC, or MP3. Each source can be included, locked, muted, or soloed. Attack, decay, sustain, release, pitch, low cut, and high cut shape the tone. Generate blends the included sources, and Undo steps back.

Drum kit

Four rows: kick, snare, hi-hat, and open hat. Each one starts from a built-in sample, and each row can load a different WAV, AIFF, FLAC, or MP3. The grid is sixteen steps.

Commit to Playlist bounces the grid into an audio clip on the first track, at the playhead. Clear Grid wipes the steps.

Mixer

Ten channel strips plus a master. Every strip has a fader, pan, mute, solo, and a meter, and six plugin slots. The stock plugins are EQ, Compressor, Reverb, Echo/Delay, and Maximizer.

F9 shows or hides the mixer. It docks in the window, under the piano roll.

VST3 instruments

A playlist track can play dSynth or a Linux VST3 instrument. The picker scans ~/.vst3, /usr/lib/vst3, and /usr/local/lib/vst3.

The project file stores the plugin file and its state, so the instrument comes back with the song. Surge XT is one instrument that format is written to remember. Windows VST3 plugins use yabridge.

WAV, MP3, and stems

Export bounces the song from a small window. Master WAV is 24-bit. Master MP3 is there when the lame encoder is installed. All stems writes a 24-bit WAV for each playlist track that has a clip.

Files are named from the project and saved in Documents/DawLunix, inside a folder called after the project.

Drag and drop

Drag WAV or MP3 audio from the file manager onto a playlist lane or a drum row. Drops work on Wayland and X11: the GNOME Wayland session and Xorg.

Windows VST3 plugins via yabridge

Windows VST3 plugins load through yabridge. They are scanned out of process, with a timeout, and loaded in the background.

The bundled yabridge is 5.1.1. It hosts 64-bit plugins only. The 32-bit host is not included.

Setup

Wine is optional. You only need it if you want to use Windows VST3 plugins through yabridge.

  1. Install wine, or wine-staging.
  2. /usr/lib/dawlunix/yabridge/yabridgectl add <your Windows VST3 folder>
  3. /usr/lib/dawlunix/yabridge/yabridgectl sync
  4. Rescan in DawLunix.

Keyboard shortcuts

These work while the main window has the keyboard. dSynth is its own window and keeps its note keys.

  • Space Play or pause
  • Enter Stop and rewind the playhead to the start
  • C Cut the selected clip at the playhead
  • S Toggle stretch on the selected clip
  • Ctrl+S Save. If the project is still Untitled, Settings opens so it can be named.
  • Home Scroll the timeline back to the start
  • Delete Delete selected piano-roll notes, or the selected clip when the piano roll is hidden. Backspace does the same.
  • F9 Show or hide the mixer
  • Escape Close a track rename or a plugin popup, then ask whether to quit

DawLunix runs fully without Wine: dSynth, drums, the mixer, export, and native Linux VST3s such as Surge XT.

Supported systems

Ubuntu 22.04 and 24.04, amd64. Built on Ubuntu 22.04.

Checksum

sha256 fd151ee9a24484f4244f04855440d3d54064f72e98ca63d21199b0f7b3f6eeb5

The hosted file is dawlunix_1.0.0-beta2_amd64.deb. The package version is 1.0.0~beta2. SHA256SUMS.txt is on the v1.0.0-beta2 pre-release.

Install

sudo apt install ./dawlunix_1.0.0-beta2_amd64.deb

apt may pull in Wine as a Recommends. To skip it:

sudo apt install --no-install-recommends ./dawlunix_1.0.0-beta2_amd64.deb

Skipping recommended packages also skips lame. Install lame separately if you want MP3 export.

Uninstall

sudo apt remove dawlunix
